ตอนเช้า — เตรียมงาน

เปิดระบบ → ดูว่าวันนี้ต้องส่งกี่ร้าน

  1. เปิดเว็บ GV Dispatch
    เลือกวันที่ทำงานมุมบน (ปฏิทิน) ให้ตรงกับวันส่งจริง
  2. เข้าเมนู งานส่ง
    กดปุ่ม ดึงจาก TRCloud เพื่อดึงบิล / เลข PO เข้ามาอัตโนมัติ
    (หรือกด + เพิ่มงานส่ง ถ้ามีบิลนอกระบบ)
  3. ดูแท็บ “รอจัดส่ง”
    ตัวเลขหลังแท็บ = จำนวนร้านที่ต้องส่งวันนี้ ที่ยังไม่ได้จัดรถ
    ตัวอย่าง: รอจัดส่ง (24) = ต้องส่ง 24 ร้าน
  4. เช็คเลข PO / เลขบิล
    คอลัมน์ เลข PO / บิล แสดง PO ลูกค้าก่อน แล้วตามด้วย KSO/BSO — ใช้ค้นหาด้านบนได้
จำไว้: ก่อนจัดรถ ดูตัวเลข “รอจัดส่ง” ให้รู้ว่าวันนี้มีกี่ร้าน ห้ามข้ามขั้นตอนนี้

จัดรถ — รวมร้านเป็นรอบส่ง

เลือกงาน → ให้ระบบจัดเส้นทาง → ยืนยันรอบ

  1. งานด่วน 1 ร้าน
    ที่แถวงาน กด จัดทีละงาน → เลือกรถ + คนขับ → ยืนยัน
  2. หลายร้านพร้อมกัน
    ติ๊กเลือกร้านในแท็บรอจัดส่ง → กด ไปวางแผน
    หรือเข้าเมนู จัดรถ → แท็บ วางแผนจัดรถ
  3. กด “จัดเส้นทางอัตโนมัติ”
    ระบบจัดลำดับร้าน / แบ่งคันให้ · ตรวจจำนวนจุดกับจำนวนร้านที่เลือกให้ตรงกัน
  4. กด “ยืนยันการส่ง”
    งานจะเปลี่ยนเป็น “วางแผนแล้ว” · สลับไปแท็บ รอบส่งวันนี้ ในหน้าจัดรถเพื่อดูทุกรอบ
เช็คไม่ให้ส่งไม่ครบ: รวมจุดส่งทุกคัน ต้องเท่ากับจำนวนร้านที่ติ๊กไว้ ถ้าไม่เท่า = ยังมีร้านหลุด

พิมพ์ใบส่ง — พิมพ์ที่ไหน

พิมพ์ก่อนออกรถ ให้คนขับถือไปส่งทีละร้าน

  1. ใบส่งต่อรอบ (แนะนำ)
    เมนู รายงาน → ประเภท สรุปรอบส่ง → กดสร้างรายงาน
    ที่แถวรอบส่ง กดปุ่ม 🖨️ พิมพ์ = พิมพ์ใบส่งของรอบนั้น (มีรายชื่อร้าน / ลำดับจุด)
  2. ดูรอบก่อนพิมพ์
    เมนู จัดรถ → แท็บ รอบส่งวันนี้ → กด รายละเอียด ดูว่ารอบนี้กี่ร้าน / กี่ชิ้น
  3. พิมพ์ติดตามพัสดุรายบิล (ถ้าต้องการ)
    เมนู ติดตาม → แท็บ ค้นหาพัสดุ → พิมพ์เลข PO หรือเลขบิล → กดพิมพ์
จำที่พิมพ์: ใบส่งรอบรถ = หน้า รายงาน (ปุ่มพิมพ์ที่แถวรอบ) · ใบรายบิล = หน้า ติดตาม → ค้นหาพัสดุ

คนขับ — ส่งของบนมือถือ

ให้คนขับอัปเดตทีละร้าน จะได้รู้ว่าร้านไหนส่งแล้ว / ยังไม่ส่ง

  1. เปิดโหมดคนขับ
    มุมบนขวา กด โหมดคนขับ → ส่งลิงก์ / ให้สแกน QR บนมือถือคนขับ
    คนขับแตะเลือกชื่อตัวเอง (ไม่ต้องใส่รหัส)
  2. รับรอบส่ง → ไปทีละร้านตามลำดับ
    ถึงร้านแล้วกดเช็คอิน / ส่งสำเร็จ (ถ่ายรูปได้)
    ถ้าส่งไม่ได้ ให้บันทึก “ส่งไม่สำเร็จ” พร้อมเหตุผล
  3. สำนักงานดูความคืบหน้า
    เมนู ติดตาม → แท็บ ภาพรวมรถ ดูว่ารถอยู่ไหน / ส่งถึงร้านไหนแล้ว

จบวัน — เช็คว่าส่งครบหรือยัง

อย่าปิดงานวันนั้นจนกว่าตัวเลขจะเคลียร์

  • เปิดเมนู วันนี้ — ดู “ค้างส่ง” เหลือกี่งาน ต้องเป็น 0 หรือรู้สาเหตุทุกใบ
  • เปิดเมนู งานส่ง — แท็บ กำลังส่ง ต้องว่าง (หรือรู้ว่าร้านไหนค้าง)
  • แท็บ เสร็จแล้ว — นับจำนวนร้านที่ส่งสำเร็จ เทียบกับที่จัดรถตอนเช้า
  • ถ้ามีร้านค้าง: จัดรอบเย็น / เลื่อนวัน / หรือบันทึกส่งไม่สำเร็จให้ครบ อย่าปล่อยเป็นรอจัดส่งเฉย ๆ
กฎสั้น ๆ: จำนวนร้านตอนเช้า (รอจัดส่ง) ≈ ส่งสำเร็จ + ส่งไม่สำเร็จ + ค้างที่รู้สาเหตุ — ห้ามมีร้านหายเงียบ
