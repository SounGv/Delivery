เริ่มต้น

การเข้าใช้งานระบบ

เปิดเว็บได้จากคอมพิวเตอร์ แท็บเล็ต หรือมือถือ ผ่านลิงก์ของบริษัท

  1. เปิดลิงก์ระบบที่บริษัทให้มา (บันทึกไว้เป็น Bookmark ได้)
  2. มุมซ้ายล่างต้องขึ้นจุดสีเขียว ● เชื่อมต่อแล้ว = ใช้ข้อมูลจริง ถ้าขึ้น โหมดทดลอง ให้แจ้งแอดมิน
  3. เมนูทั้งหมดอยู่แถบซ้าย · บนมือถือแตะเมนูด้านล่างจอ
⚡
เปิดครั้งแรกแล้วข้อมูลไม่ขึ้น หรือขึ้น "โหมดทดลอง"? กด Ctrl + Shift + R (ค้างปุ่มพร้อมกัน) เพื่อล้างแคชแล้วโหลดใหม่ — จะเชื่อมข้อมูลจริงทันที · บนมือถือ: ปิดแท็บแล้วเปิดใหม่ หรือล้างแคชเบราว์เซอร์

ปุ่มที่ใช้บ่อยด้านบน

  • ปฏิทิน (มุมบนซ้าย) — เลือกวันที่ทำงาน ข้อมูลทั้งหน้าจะเปลี่ยนตามวันที่เลือก
  • ช่องค้นหา — พิมพ์ชื่อลูกค้า / เลขบิล เพื่อกรองงานในหน้ารายการ
ℹ️
ฟังก์ชันแบ่งตามหน้าที่: ผู้จัดการ/แอดมิน ใช้จัดงาน–จัดรถ–ดูรายงาน · คนขับ ใช้ “โหมดคนขับ” บนมือถือ
ภาพรวม

1 แดชบอร์ด (Dashboard)

หน้าแรก — ดูสรุปงานของวันได้ทันทีในหน้าเดียว

  • การ์ด KPI ด้านบน — งานทั้งหมด / รอจัด Route / วางแผนแล้ว / กำลังส่ง / สำเร็จ / ไม่สำเร็จ (พร้อมจำนวนกล่อง)
  • สรุปต้นทุนวันนี้ — ต้นทุนรวม, รถบริษัท, รถนอก, เฉลี่ยต่อ Route / จุด / กล่อง
  • แผนที่เส้นทางวันนี้ — เห็นคลัง 🏭 จุดส่ง และรถ
  • งานที่ต้องจัด Route — งานที่ยังไม่ได้จัดรถ กดปุ่ม จัด Route เพื่อไปวางแผน
🔄
ปุ่ม รีเฟรช ดึงข้อมูลล่าสุด · ตำแหน่งรถอัปเดตอัตโนมัติทุกไม่กี่วินาที
งานประจำวัน · ผู้จัดการ/แอดมิน

2 งานส่งสินค้า

บันทึกออเดอร์ที่ต้องส่ง — 1 รายการ = 1 งาน/บิล

เพิ่มงานส่งใหม่

  1. กดปุ่ม + เพิ่มงานส่ง มุมขวาบน
  2. เลือกลูกค้า/สาขา จากรายการ (ระบบเติมที่อยู่ให้อัตโนมัติ) หรือพิมพ์เอง
  3. กรอก เลขบิล · จำนวนกล่อง · ที่อยู่ · รหัสไปรษณีย์
  4. เลือก Priority — ด่วน / ปกติ / ไม่เร่งด่วน
  5. กด บันทึก — ระบบหาพิกัด GPS จากที่อยู่ให้เอง ไม่ต้องกรอกพิกัดเอง

แก้ไข / ลบ

  • ไอคอน ✏️ = แก้ไข · 🗑️ = ลบ (เป็นการซ่อน ข้อมูลจริงไม่หายถาวร)
⚡
จัดรถด่วน — งานสถานะ “ร่าง” มีปุ่ม จัดรถด่วน กดแล้วเลือกรถ+คนขับ ระบบคำนวณระยะ/ต้นทุนให้ ยืนยันจ่ายรถได้ในคลิกเดียว เหมาะกับส่งด่วนใบเดียว
งานประจำวัน · ผู้จัดการ/แอดมิน

3 วางแผนเส้นทาง (จัด Route)

รวมหลายงานเป็น 1 รอบส่ง — ระบบจัดลำดับจุด คำนวณระยะทางถนนจริง และต้นทุนให้

  1. เลือกวันที่ที่ต้องการจัด (ปุ่มปฏิทินด้านบน)
  2. ฝั่งซ้าย — ติ๊กเลือกงาน ที่จะส่งในรอบเดียวกัน
  3. กดปุ่ม วางแผน Route อัตโนมัติ
  4. ระบบจะ: จัดลำดับจุดส่ง (ลดการย้อนทาง) · วาดเส้นทางตามถนนจริงบนแผนที่ · คำนวณระยะ/เวลา/ต้นทุน
  5. ในกล่อง รถ & คนขับที่จะใช้ — เลือก รถบริษัท หรือ รถภายนอก → เลือกคันที่ใช้ → ใส่ชื่อคนขับ
  6. ตรวจ/แก้ ค่าทางด่วน และ ค่าจอดรถ ในกล่องต้นทุนให้ตรงจริง (ยอดรวมอัปเดตทันที)
  7. กด ยืนยัน Route นี้ — งานจะกลายเป็น “วางแผนแล้ว” และเข้าไปอยู่ในรอบส่งสินค้า
ระบบคิดต้นทุนอย่างไรวิธีคิด
ค่าน้ำมันระยะทางถนนจริง × เรตค่าน้ำมันของรถ (อัตโนมัติ)
ค่าจอดรถคิดเฉพาะปลายทางที่เป็นห้าง/ศูนย์การค้า · ร้านเดี่ยว = 0 (แก้เองได้)
ค่าทางด่วนใส่ตามจริง — ถ้าไม่ขึ้นทางด่วนให้ใส่ 0
🅰️
มี ทางเลือก A/B/C ให้เปรียบเทียบ (รถบริษัทล้วน / รถบริษัท+รถนอก / แบ่ง 2 รอบ) แตะแล้วเติมค่าในฟอร์มให้อัตโนมัติ ถ้ารถบริษัทจุไม่พอ ระบบจะเตือน
งานประจำวัน · ผู้จัดการ/แอดมิน

4 รอบส่งสินค้า

รายการ Route ที่จัดแล้วของวันนั้น

  • เริ่มรอบ — เปลี่ยนสถานะเป็น “กำลังส่ง” (ใช้เมื่อรถออกจริง)
  • แก้ไข — เปลี่ยนรถ / คนขับ / สถานะ / ค่าใช้จ่าย (ยอดคำนวณใหม่ให้)
  • รายละเอียด — ดูลำดับจุดส่ง + เส้นทางบนแผนที่
  • ปุ่ม CSV — ดาวน์โหลดรายการ Route
งานประจำวัน

5 ติดตามพัสดุ

เช็คสถานะพัสดุรายชิ้น — ใช้ตอบลูกค้าได้ทันที

  1. พิมพ์ เลขบิล / เลขที่ PO / ชื่อลูกค้า ในช่องค้นหา แล้วกด ค้นหา
  2. ดูไทม์ไลน์: สร้างงาน → วางแผน → กำลังส่ง → เช็คอินถึงจุด (GPS) → ส่งสำเร็จ/ไม่สำเร็จ
  3. กดปุ่ม 🖨️ เพื่อพิมพ์ใบติดตามพัสดุ
งานประจำวัน

6 แผนที่ติดตาม (Live Map)

ดูตำแหน่งรถสด ๆ ทุกคันบนแผนที่

  • หมุดสีเขียวมีป้าย 🏭 คลัง = จุดคลังบริษัท · หมุดรถ = ตำแหน่ง GPS สดจาก Cartrack
  • ตัวกรองด้านบน: ทั้งหมด / รถบริษัท / รถภายนอก / กำลังวิ่ง / จอดอยู่
  • แผงขวาแสดงสถานะรถแต่ละคัน อัตโนมัติจากความเร็ว GPS — กำลังวิ่ง (มีความเร็ว) / จอดอยู่ (ความเร็ว 0) / ออฟไลน์ (ไม่มีสัญญาณ)
ข้อมูลหลัก · ผู้จัดการ/แอดมิน

7 รถบริษัท & รถจ้างภายนอก

รถบริษัท

  • เพิ่ม/แก้/ลบรถ · ตั้ง ความจุ (กล่อง) และ ค่าน้ำมัน/กม. เพื่อให้คำนวณต้นทุนแม่น
  • ช่อง Cartrack Registration = ทะเบียนที่ผูกกับ GPS (ต้องตรงจึงจะเห็นตำแหน่งสด)

รถจ้างภายนอก

  • บันทึกผู้ให้บริการ / คนขับ / ทะเบียน / ความจุ / เรตราคา (ต่อเที่ยว / ต่อกม. / ต่อวัน) — ระบบใช้คิดต้นทุนตอนจัด Route
ข้อมูลหลัก · ผู้จัดการ/แอดมิน

8 ลูกค้า / สาขา & พนักงาน

ลูกค้า / สาขา

  1. กด + เพิ่มลูกค้า → กรอกชื่อร้าน · สาขา · ที่อยู่ · รหัสไปรษณีย์
  2. กด ค้นหาพิกัด GPS จากที่อยู่ — ระบบหาพิกัดให้อัตโนมัติ (ไม่ต้องกรอกเอง)
  3. กดบันทึก · ลูกค้าที่มีพิกัดจะขึ้นหมุดบนแผนที่และใช้จัด Route ได้

พนักงานส่งสินค้า

  • เพิ่ม/แก้/ลบ ชื่อคนขับ เบอร์โทร ตำแหน่ง และรถประจำ — ชื่อจะขึ้นให้เลือกตอนจัด Route
การเงิน · ผู้จัดการ/แอดมิน

9 ค่าใช้จ่าย & เงินทดรองจ่าย

ค่าใช้จ่าย

  • บันทึกค่าน้ำมัน / ทางด่วน / จอดรถ / อื่น ๆ ผูกกับ Route ได้

เงินทดรองจ่าย (เคลียร์เงินคนขับ)

  1. กด เคลียร์เงินทดรอง → เลือก Route + คนขับ
  2. ใส่ เบิกเงินทดรอง และ ใช้จริง
  3. ระบบคำนวณ เงินทอน (เบิก>ใช้จริง) หรือ เบิกเพิ่ม (ใช้จริง>เบิก) ให้อัตโนมัติ

ต้นทุนต่อ Route

  • ตารางแยกค่าน้ำมัน/ทางด่วน/จอด/รถนอก + ต่อจุด + ต่อกล่อง · Export Excel ได้

10 รายงาน & การพิมพ์

  1. เลือก ช่วงวันที่ (หรือปุ่มลัด วันนี้ / 7 วัน / เดือนนี้) แล้วกด สร้างรายงาน
  2. ดูสรุป จำนวนงาน · Route · จุดส่ง · กล่อง · ระยะทาง · ต้นทุน + กราฟ
  3. เลือกขนาดกระดาษ A4 / A5

11 โหมดคนขับ (บนมือถือ)

ใช้ระหว่างวิ่งงาน — ปุ่มใหญ่ กดง่ายด้วยมือเดียว

  1. เปิดเว็บบนมือถือ → แตะเมนูล่าง คนขับ
  2. ดูรอบส่งของตัวเอง: จำนวนจุด · กล่อง · ความคืบหน้า
  3. แตะ เริ่มรอบส่ง เมื่อออกรถ
  4. ที่จุดปัจจุบัน: เปิดแผนที่ นำทาง · Check-in เมื่อถึงจุด (ระบบเช็ก GPS ว่าใกล้จุดไหม)
  5. ส่งเสร็จ → แตะ ส่งเสร็จ · ส่งไม่ได้ → ส่งไม่สำเร็จ แล้วใส่เหตุผล
สัญญาณ Check-inความหมาย
🟢 ถึงจุดส่งอยู่ห่างจุดส่ง ไม่เกิน 100 เมตร
🟡 ใกล้จุดส่งห่าง 100–500 เมตร
🔴 ยังไม่ถึงห่างเกิน 500 เมตร
📍
ครั้งแรกมือถือจะขออนุญาตเข้าถึงตำแหน่ง — ต้องกด “อนุญาต” ไม่งั้น Check-in ด้วย GPS จะใช้ไม่ได้

คำถามที่พบบ่อย

เปิดมาไม่เห็นข้อมูล / ขึ้น “โหมดทดลอง”

เบราว์เซอร์ยังไม่เชื่อมระบบ — เปิดด้วยลิงก์ที่บริษัทให้ (ที่มี ?api=) หรือให้แอดมินตั้งค่าที่หน้า “ตั้งค่าระบบ” แล้วรีเฟรชด้วย Ctrl+Shift+R

เห็นข้อมูลไม่ครบ / วันที่ไม่ตรง

ตรวจว่าเลือก วันที่ ถูก (ปุ่มปฏิทินบนซ้าย) — ข้อมูลแสดงตามวันที่เลือก

ตำแหน่งรถไม่ขยับ / ขึ้นสีเหลือง “ข้อมูลอาจไม่ใหม่”

GPS Cartrack ยังไม่อัปเดต — รอสักครู่ หรือแจ้งแอดมินให้ตรวจการเชื่อมต่อ Cartrack
