การเข้าใช้งานระบบ

เปิดเว็บได้จากคอมพิวเตอร์ แท็บเล็ต หรือมือถือ ผ่านลิงก์ของบริษัท

  1. เปิดลิงก์ระบบที่บริษัทให้มาแนะนำให้กด Bookmark / เพิ่มลงหน้าจอมือถือ ไว้เปิดได้เร็ว
  2. มุมซ้ายล่างต้องขึ้นจุดสีเขียว ● เชื่อมต่อแล้ว= กำลังใช้ข้อมูลจริงจาก Google Sheet ของบริษัท
  3. เมนูทั้งหมดอยู่แถบซ้าย · บนมือถือใช้เมนูแถบล่างจอ

ทำความเข้าใจสถานะการเชื่อมต่อ (มุมซ้ายล่าง)

สัญญาณความหมายต้องทำอะไร
🟢 เชื่อมต่อแล้วใช้ข้อมูลจริง บันทึกขึ้นเซิร์ฟเวอร์ปกติใช้งานได้เลย
🟡 กำลังเชื่อมต่อ…กำลังโหลดข้อมูลจากเซิร์ฟเวอร์ (ตอนเปิดครั้งแรก)รอสักครู่ ระบบจะเชื่อมให้เอง
🟡 กำลังลองเชื่อมต่อใหม่…เน็ตสะดุด/เซิร์ฟเวอร์ตอบช้าชั่วคราวไม่ต้องทำอะไร ระบบจะเชื่อมกลับให้อัตโนมัติ
🟡 โหมดทดลอง (Mock)ยังไม่ได้ผูกลิงก์ข้อมูลจริง — ข้อมูลที่เห็นเป็นข้อมูลตัวอย่างเปิดด้วยลิงก์บริษัท หรือแจ้งแอดมิน แล้วกด Ctrl+Shift+R
⚡
บันทึกไวขึ้นแล้ว — เมื่อกดบันทึก/แก้ไข/ลบ ข้อมูลจะขึ้นทันที ไม่ต้องรอ ระบบซิงค์ขึ้นเซิร์ฟเวอร์ให้เบื้องหลังเอง และสถานะที่คนขับอัปเดตจากมือถือจะเด้งขึ้นหน้าออฟฟิศเองทุก ๆ ไม่กี่วินาที
🔄
เปิดครั้งแรกแล้วข้อมูลไม่ขึ้น หรือขึ้น “โหมดทดลอง”? กด Ctrl + Shift + R (ค้างพร้อมกัน) เพื่อล้างแคชแล้วโหลดใหม่ · บนมือถือ: ปิดแท็บแล้วเปิดใหม่

ปุ่มที่ใช้บ่อยด้านบน

  • 📅 ปฏิทิน (มุมบนซ้าย) — เลือกวันที่ทำงาน ข้อมูลทั้งหน้าจะเปลี่ยนตามวันที่เลือก (มีปุ่มลัด “วันนี้”)
  • 🔍 ช่องค้นหา — พิมพ์ชื่อลูกค้า / เลขบิล เพื่อกรองรายการในหน้าที่กำลังดู
  • 🔔 กระดิ่ง — ตัวเลขคือจำนวนงานที่ยัง “รอจัด Route”
👥
ระบบแบ่งการใช้งานเป็น 2 บทบาท: ผู้จัดการ/แอดมิน ใช้ตั้งค่า–สร้างงาน–จัดรถ–ดูรายงาน (บนคอม) · คนขับ ใช้ “โหมดคนขับ” บนมือถือระหว่างวิ่งงาน
แผนผังการใช้งาน

ลำดับการเริ่มใช้งานครั้งแรก

ทำตามลำดับนี้ครั้งเดียวตอนเริ่มระบบ หลังจากนั้นงานประจำวันจะเริ่มที่ข้อ 5 เป็นต้นไป

  1. ตั้งค่าระบบใส่ข้อมูลบริษัท พิกัดคลัง และพารามิเตอร์ต้นทุน (ค่าน้ำมัน/กม., ค่าทางด่วน, ค่าจอด) → ดูหัวข้อ A
  2. เพิ่มลูกค้า / สาขาใส่ร้าน + สาขา + ที่อยู่ ระบบหาพิกัด GPS ให้อัตโนมัติ → หัวข้อ B
  3. เพิ่มพนักงานส่งสินค้า (คนขับ)ชื่อ เบอร์ ตำแหน่ง และรถประจำ → หัวข้อ C
  4. เพิ่มรถบริษัท / รถจ้างภายนอกตั้งความจุกล่อง + ค่าน้ำมัน/เรตราคา เพื่อคำนวณต้นทุนแม่น → หัวข้อ D
  5. สร้างงานส่งสินค้าบันทึกออเดอร์ที่ต้องส่งของวันนั้น → หัวข้อ 2
  6. วางแผนเส้นทาง (จัด Route)รวมงานเป็นรอบ จัดลำดับจุด คิดต้นทุน → หัวข้อ 3
  7. มอบหมายงานให้คนขับคนขับกด “รับงาน” บนมือถือ สถานะขึ้น “กำลังส่ง” อัตโนมัติ → หัวข้อ 4–5
  8. ติดตามงานดูความคืบหน้า/ตำแหน่งรถ + ตอบลูกค้าด้วยหน้าติดตามพัสดุ → หัวข้อ 6–7
  9. ดึงรายงาน & พิมพ์เอกสารสรุปงาน/ต้นทุน + พิมพ์ใบส่งของ/ใบเบิกค่าใช้จ่าย → หัวข้อ 9
ตั้งค่าก่อนใช้งาน · ผู้จัดการ/แอดมิน

A ตั้งค่าระบบ

เมนู ตั้งค่าระบบ (มุมซ้ายล่าง) — ตั้งค่าพวกนี้ให้ครบ “ก่อน” ใช้งานจริง เพราะค่าต้นทุนและพิกัดคลังคือฐานที่ระบบใช้คำนวณระยะทาง/ราคาทุก Route

1) ข้อมูลบริษัท & คลังสินค้า

ช่องใส่อะไร / มีผลอย่างไร
ชื่อบริษัท COMPANY_NAMEชื่อที่จะขึ้นหัวเอกสารทุกใบที่พิมพ์ (ใบส่งของ / ใบเบิก / รายงาน)
ชื่อคลังสินค้า WAREHOUSE_NAMEชื่อจุดตั้งต้น จะขึ้นบนแผนที่ที่หมุด 🏭
ที่อยู่คลังสินค้า WAREHOUSE_ADDRESSพิมพ์บนหัวเอกสาร
พิกัดคลัง Lat/Lng WAREHOUSE_LAT / LNGสำคัญมาก — เป็นจุด เริ่มต้นและสิ้นสุด ของทุกเส้นทาง ระบบวัดระยะทาง/ค่าน้ำมันจากจุดนี้ ต้องใส่ให้ตรงคลังจริง
📍
หาพิกัดคลังยังไง: เปิด Google Maps → คลิกขวาที่ตำแหน่งคลัง → ตัวเลขคู่แรกที่ขึ้นคือ Latitude, Longitude คัดลอกมาใส่ได้เลย

2) พารามิเตอร์ต้นทุน

ช่องใส่อะไร / มีผลอย่างไร
ค่าน้ำมันต่อกิโลเมตร FUEL_COST_PER_KMบาท/กม. — ใช้เป็น ค่ากลาง คิดค่าน้ำมัน (ระยะทาง × ค่านี้) หากรถคันไหนตั้งค่าน้ำมันเฉพาะไว้ จะใช้ของคันนั้นแทน
ความเร็วเฉลี่ย AVG_SPEED_KMHกม./ชม. — ใช้ประเมิน เวลาที่คาดว่าจะใช้ ของแต่ละรอบ (เมืองหนาแน่นตั้ง 25–30 ก็พอ)
ค่าทางด่วนเริ่มต้น DEFAULT_TOLLบาท — เติมให้เป็นค่าตั้งต้นตอนจัด Route (แก้รายรอบได้ ถ้าไม่ขึ้นทางด่วนใส่ 0)
ค่าจอดรถเริ่มต้น DEFAULT_PARKINGบาท/จุด — ระบบคิด เฉพาะปลายทางที่เป็นห้าง/ศูนย์การค้า (ร้านเดี่ยว = 0) เป็นค่าตั้งต้น แก้ได้

3) การติดตาม (GPS Check-in)

  • ระยะ Check-in สีเขียว PROXIMITY_GREEN_M — คนขับต้องเข้าใกล้จุดส่งไม่เกินกี่เมตรถึงนับว่า “ถึงจุดแล้ว” (ค่าแนะนำ 100 ม.)
  • ระยะ Check-in สีเหลือง PROXIMITY_YELLOW_M — ระยะ “ใกล้จุดส่ง” (ค่าแนะนำ 500 ม.) เกินกว่านี้ = 🔴 ยังไม่ถึง

4) บันทึกการตั้งค่า

  1. แก้ค่าในช่องต่าง ๆ ทางด้านซ้ายให้ครบ
  2. กดปุ่ม 💾 บันทึกการตั้งค่าทั้งหมด (การ์ดขวาล่าง)ค่าจะถูกเขียนกลับไปเก็บใน Google Sheets (ชีต Settings) ทันที
⚙️
Cartrack Integration (เมนูล่างสุด) ใช้ผูก GPS ติดตามรถแบบเรียลไทม์ — การตั้งค่ารหัสเชื่อมต่อเป็นหน้าที่ แอดมิน/ผู้ดูแลระบบ เท่านั้น (ตั้งในระบบหลังบ้าน ไม่กรอกในเว็บ) ผู้ใช้ทั่วไปแค่ดูสถานะว่าเชื่อมต่ออยู่หรือไม่
ตั้งค่าก่อนใช้งาน · ผู้จัดการ/แอดมิน

B ลูกค้า / สาขา

เมนู ลูกค้า / สาขา — ทะเบียนร้าน/สาขาปลายทาง เพิ่มไว้ล่วงหน้าเพื่อเลือกได้เร็วตอนสร้างงานส่ง

  1. กด + เพิ่มลูกค้า มุมขวาบน
  2. กรอก ชื่อร้าน · สาขา · ที่อยู่ · รหัสไปรษณีย์ใส่ที่อยู่ให้ครบ ระบบจะหาพิกัดได้แม่นขึ้น
  3. กด ค้นหาพิกัด GPS จากที่อยู่ — ระบบหาพิกัดให้อัตโนมัติไม่ต้องกรอก Lat/Lng เอง
  4. กด บันทึก
  • ไอคอน ✏️ = แก้ไข · 🗑️ = ลบ (ซ่อนออกจากรายการ ข้อมูลจริงกู้คืนได้)
  • ใช้ช่องค้นหาด้านบนเพื่อหาลูกค้าเร็ว ๆ
🗺️
ลูกค้าที่ ไม่มีพิกัด GPS จะไม่ขึ้นบนแผนที่และจัด Route อัตโนมัติไม่ได้ — ควรกดหาพิกัดให้เรียบร้อยก่อนบันทึก
ตั้งค่าก่อนใช้งาน · ผู้จัดการ/แอดมิน

C พนักงานส่งสินค้า

เมนู พนักงานส่งสินค้า — รายชื่อคนขับ/ผู้ช่วย ที่จะเลือกไปผูกกับรอบส่ง

  1. กด + เพิ่มพนักงาน
  2. กรอก ชื่อ-นามสกุล · เบอร์โทร
  3. เลือก ตำแหน่ง — คนขับ / ผู้ช่วย / ธุรการ
  4. เลือก รถประจำ (ถ้ามี) แล้วกด บันทึกชื่อคนขับจะถูกเติมให้อัตโนมัติเมื่อเลือกรถคันนั้นตอนจัด Route
ตั้งค่าก่อนใช้งาน · ผู้จัดการ/แอดมิน

D รถบริษัท & รถจ้างภายนอก

รถบริษัท

  1. เมนู รถบริษัท → กด + เพิ่มรถ
  2. กรอก ชื่อรถ · ทะเบียน · ประเภท (กระบะ/หกล้อ/ตู้)
  3. ตั้ง ความจุ (กล่อง) — ระบบใช้เช็กว่ารถรับงานไหวไหมตอนจัด Route
  4. ตั้ง ค่าน้ำมัน/กม. ของรถคันนั้น (ถ้าเว้นไว้ ใช้ค่ากลางจากหน้าตั้งค่า)
  5. ช่อง Cartrack Registration = ทะเบียนที่ผูกกับกล่อง GPS ต้องตรงจึงจะเห็นตำแหน่งสด
🚦
สถานะรถขึ้น อัตโนมัติจากความเร็ว GPS: กำลังวิ่ง (มีความเร็ว) · จอดอยู่ (ความเร็ว 0) · ออฟไลน์ (ไม่มีสัญญาณ) — ไม่ต้องตั้งเอง

รถจ้างภายนอก

  • เมนู รถจ้างภายนอก — บันทึก ผู้ให้บริการ / คนขับ / เบอร์ / ทะเบียน / ความจุ
  • ตั้ง เรตราคา และ รูปแบบ — ต่อเที่ยว / ต่อกิโลเมตร / ต่อวันระบบใช้เรตนี้คิดต้นทุนอัตโนมัติเมื่อเลือกรถภายนอกตอนจัด Route
งานประจำวัน · ภาพรวม

1 แดชบอร์ด (Dashboard)

หน้าแรก — ดูสรุปงานของวันได้ทันทีในหน้าเดียว

  • การ์ด KPI แถวบน — งานทั้งหมด / รอจัด Route / วางแผนแล้ว / กำลังส่ง / สำเร็จ / ไม่สำเร็จ (พร้อมจำนวนกล่อง)
  • สรุปต้นทุนวันนี้ — ต้นทุนรวม, รถบริษัท, รถนอก, เฉลี่ยต่อ Route / ต่อจุด / ต่อกล่อง
  • แผนที่เส้นทางวันนี้ — เห็นคลัง 🏭 จุดส่ง และตำแหน่งรถ
  • งานที่ต้องจัด Route — งานที่ยังไม่ได้จัดรถ มีปุ่ม จัด Route พาไปวางแผน
  • กิจกรรมล่าสุด — ประวัติการสร้างงาน/จัดรถ/ส่งสำเร็จ ล่าสุด
🔄
ปุ่ม รีเฟรช ดึงข้อมูลล่าสุดทั้งหมด · ตำแหน่งรถและตัวเลขสรุปอัปเดตอัตโนมัติทุกไม่กี่วินาที
งานประจำวัน · ผู้จัดการ/แอดมิน

2 สร้างงานส่งสินค้า

เมนู งานส่งสินค้า — บันทึกออเดอร์ที่ต้องส่ง · 1 รายการ = 1 งาน / 1 บิล

ขั้นตอนสร้างงาน (ทีละสเต็ป)

  1. เลือกวันที่ ให้ตรงวันส่งก่อน (ปุ่มปฏิทินบนซ้าย)
  2. กดปุ่ม + เพิ่มงานส่ง มุมขวาบน
  3. เลือกลูกค้า / สาขา จากรายการที่เตรียมไว้ระบบเติมที่อยู่ + พิกัดให้อัตโนมัติทันที · หรือจะพิมพ์ชื่อ/ที่อยู่เองก็ได้
  4. กรอก เลขบิล และ จำนวนกล่อง
  5. เลือก Priority — ด่วน / ปกติ / ไม่เร่งด่วนมีผลกับการจัดลำดับจุดส่งตอนวางแผนเส้นทาง
  6. ใส่ หมายเหตุ ถ้ามี (เช่น โทรก่อนส่ง / ของแตกหักง่าย)
  7. กด บันทึกงานขึ้นในรายการทันที · ถ้ากรอกที่อยู่เองโดยยังไม่มีพิกัด ระบบจะหาพิกัด GPS ให้อัตโนมัติ

แก้ไข / ลบ / เปลี่ยนสถานะ

  • ไอคอน ✏️ = แก้ไข — แก้ได้ทุกช่อง รวมถึง สถานะ (ผู้จ่ายงานปรับสถานะเองได้ที่นี่)
  • ไอคอน 🗑️ = ลบ (ซ่อนออกจากรายการ ข้อมูลจริงกู้คืนได้)
  • ปุ่ม CSV = ดาวน์โหลดรายการงานของวันนั้น
⚡
จัดรถด่วน — งานสถานะ “ร่าง” จะมีปุ่ม จัดรถด่วน กดแล้วเลือกรถ+คนขับ ระบบคำนวณระยะ/ต้นทุนให้ทันที ยืนยันจ่ายรถได้ในคลิกเดียว เหมาะกับส่งด่วนใบเดียวไม่ต้องรวมรอบ
งานประจำวัน · ผู้จัดการ/แอดมิน

3 วางแผนเส้นทาง (จัด Route)

เมนู วางแผนเส้นทาง — รวมหลายงานเป็น 1 รอบส่ง ระบบจัดลำดับจุด คำนวณระยะทางถนนจริง และต้นทุนให้

  1. เลือกวันที่ที่ต้องการจัด (ปุ่มปฏิทินด้านบน)
  2. ฝั่งซ้าย — ติ๊กเลือกงาน ที่จะส่งในรอบเดียวกัน
  3. กดปุ่ม วางแผน Route อัตโนมัติระบบจะจัดลำดับจุด (ลดการย้อนทาง) · วาดเส้นทางตามถนนจริงบนแผนที่ · คำนวณระยะ/เวลา/ต้นทุน
  4. ในกล่อง รถ & คนขับที่จะใช้ — เลือก รถบริษัท หรือ รถภายนอก → เลือกคัน → ใส่/ยืนยันชื่อคนขับ
  5. ตรวจ/แก้ ค่าทางด่วน และ ค่าจอดรถ ให้ตรงจริง (ยอดรวมอัปเดตทันที)
  6. กด ยืนยัน Route นี้งานทุกใบในรอบจะกลายเป็น “วางแผนแล้ว” และเข้าไปอยู่ในหน้า “รอบส่งสินค้า” ทันที
ระบบคิดต้นทุนอย่างไรวิธีคิด
ค่าน้ำมันระยะทางถนนจริง × เรตค่าน้ำมันของรถ (อัตโนมัติ)
ค่าจอดรถคิดเฉพาะปลายทางที่เป็นห้าง/ศูนย์การค้า · ร้านเดี่ยว = 0 (แก้เองได้)
ค่าทางด่วนใส่ตามจริง — ถ้าไม่ขึ้นทางด่วนใส่ 0
🅰️
มี ทางเลือก A/B/C ให้เปรียบเทียบ (รถบริษัทล้วน / รถบริษัท+รถนอก / แบ่ง 2 รอบ) แตะแล้วเติมค่าในฟอร์มให้อัตโนมัติ ถ้ารถบริษัทจุไม่พอ ระบบจะเตือน
งานประจำวัน · ผู้จัดการ/แอดมิน

4 มอบหมายงาน & รอบส่งสินค้า

เมนู รอบส่งสินค้า — รายการ Route ที่จัดแล้วของวันนั้น จุดที่ผู้จ่ายงานควบคุมสถานะ

สิ่งที่ทำได้ในแต่ละ Route

  • เริ่มรอบ — เปลี่ยนสถานะเป็น “กำลังส่ง” (ใช้เมื่อรถออกจริง)
  • แก้ไข — เปลี่ยนรถ / คนขับ / สถานะ / ค่าใช้จ่าย (ยอดคำนวณใหม่ให้ทันที)
  • รายละเอียด — ดูลำดับจุดส่ง + เส้นทางบนแผนที่
  • ปุ่ม CSV — ดาวน์โหลดรายการ Route

การมอบหมายให้คนขับ

การมอบหมายทำได้ 2 ทาง:

  • ให้คนขับกดรับเอง — คนขับเปิดมือถือ เข้า “โหมดคนขับ” แล้วกด รับงานนี้ ที่รอบของตัวเอง · สถานะจะขึ้น “กำลังส่ง” อัตโนมัติ ผู้จ่ายงานเห็นทันที
  • ผู้จ่ายงานปรับให้ — กด แก้ไข ที่ Route แล้วเปลี่ยนคนขับ/สถานะเอง
🔁
สถานะ “ซิงค์อัตโนมัติ” — เมื่อคนขับเช็คอิน/ส่งสำเร็จบนมือถือ สถานะจะเด้งขึ้นหน้าออฟฟิศเองภายในไม่กี่วินาที ไม่ต้องกดรีเฟรช
งานประจำวัน · คนขับ

5 โหมดคนขับ (บนมือถือ)

ใช้ระหว่างวิ่งงาน — ปุ่มใหญ่ กดง่ายด้วยมือเดียว

  1. เปิดเว็บบนมือถือ → แตะเมนูล่าง คนขับ
  2. กด รับงานนี้ ที่รอบของตัวเองสถานะขึ้น “กำลังส่ง” อัตโนมัติ · ผู้จ่ายงานเห็นทันที
  3. ดูรอบส่ง: จำนวนจุด · กล่อง · ความคืบหน้า (กี่จุดจากทั้งหมด)
  4. ที่จุดปัจจุบัน กด เปิดแผนที่ เพื่อนำทาง
  5. ถึงจุดแล้วกด Check-in — ระบบเช็ก GPS ว่าอยู่ใกล้จุดหรือยัง
  6. ส่งเสร็จ → กด ส่งเสร็จ แล้ว ถ่ายรูปหลักฐาน (หน้าร้าน/ลายเซ็น/พัสดุ) → ยืนยันสถานะจุดนั้นขึ้น “ส่งสำเร็จ” พร้อมแนบรูปทันที
  7. ส่งไม่ได้ → กด ส่งไม่สำเร็จ แล้วใส่เหตุผล (เช่น ร้านปิด / ลูกค้าไม่รับ)
สัญญาณ Check-inความหมาย
🟢 ถึงจุดส่งอยู่ห่างจุดส่งไม่เกินระยะสีเขียว (ค่าเริ่มต้น 100 ม.)
🟡 ใกล้จุดส่งห่างระหว่างระยะเขียว–เหลือง (100–500 ม.)
🔴 ยังไม่ถึงห่างเกินระยะสีเหลือง
📍
ครั้งแรกมือถือจะขออนุญาตเข้าถึงตำแหน่ง — ต้องกด “อนุญาต” ไม่งั้น Check-in ด้วย GPS จะใช้ไม่ได้
งานประจำวัน · ติดตามงาน

6 ติดตามพัสดุ

เมนู ติดตามพัสดุ — เช็คสถานะพัสดุรายชิ้น ใช้ตอบลูกค้าได้ทันที

  1. พิมพ์ เลขบิล / เลขที่ PO / ชื่อลูกค้า แล้วกด ค้นหา
  2. ดูไทม์ไลน์: สร้างงาน → วางแผน → กำลังส่ง → เช็คอินถึงจุด (GPS) → ส่งสำเร็จ/ไม่สำเร็จ (พร้อมรูปหลักฐาน)
  3. กดปุ่ม 🖨️ เพื่อพิมพ์ ใบติดตามพัสดุ (A5)
งานประจำวัน · ติดตามงาน

7 แผนที่ติดตาม (Live Map)

เมนู แผนที่ติดตาม — ดูตำแหน่งรถสด ๆ ทุกคันบนแผนที่

  • หมุด 🏭 คลัง = จุดคลังบริษัท · หมุดรถ = ตำแหน่ง GPS สดจาก Cartrack
  • ตัวกรองด้านบน: ทั้งหมด / รถบริษัท / รถภายนอก / กำลังวิ่ง / จอดอยู่
  • แผงขวาแสดงสถานะรถแต่ละคัน อัตโนมัติจากความเร็ว GPS — กำลังวิ่ง / จอดอยู่ / ออฟไลน์
🛰️
ถ้าตำแหน่งไม่ขยับหรือขึ้น “ข้อมูลอาจไม่ใหม่” = GPS Cartrack ยังไม่อัปเดต รอสักครู่ หรือแจ้งแอดมินให้ตรวจการเชื่อมต่อ
การเงิน · ผู้จัดการ/แอดมิน

8 ค่าใช้จ่าย & เงินทดรองจ่าย

ค่าใช้จ่าย

  • เมนู ค่าใช้จ่าย — บันทึกค่าน้ำมัน / ทางด่วน / จอดรถ / อื่น ๆ ผูกกับ Route ได้ · ดาวน์โหลด CSV ได้

เงินทดรองจ่าย (เคลียร์เงินคนขับ)

  1. เมนู เงินทดรองจ่าย → กด เคลียร์เงินทดรอง
  2. เลือก Route + ใส่ชื่อคนขับ
  3. ใส่ เบิกเงินทดรอง และ ใช้จริง
  4. ระบบคำนวณ เงินทอน (เบิก>ใช้จริง) หรือ เบิกเพิ่ม (ใช้จริง>เบิก) ให้อัตโนมัติ

ต้นทุนต่อ Route

  • เมนู ต้นทุนต่อ Route — ตารางแยกค่าน้ำมัน/ทางด่วน/จอด/รถนอก + ต่อจุด + ต่อกล่อง · Export Excel ได้
รายงาน · ผู้จัดการ/แอดมิน

9 รายงาน & การพิมพ์

  1. เมนู รายงาน → เลือก ช่วงวันที่ (หรือปุ่มลัด วันนี้ / 7 วัน / เดือนนี้) แล้วกด สร้างรายงาน
  2. ดูสรุป: จำนวนงาน · Route · จุดส่ง · กล่อง · ระยะทาง · ต้นทุน + กราฟ

คำถามที่พบบ่อย

บันทึกแล้วต้องรอนานไหม?

ไม่ต้องรอ — ข้อมูลขึ้นทันทีที่กดบันทึก ระบบซิงค์ขึ้นเซิร์ฟเวอร์ให้เบื้องหลังเอง หากมีปัญหาเชื่อมต่อ ระบบจะแจ้งเตือนและย้อนข้อมูลกลับให้

เปิดมาไม่เห็นข้อมูล / ขึ้น “โหมดทดลอง”

เปิดด้วยลิงก์บริษัท (ที่มี ?api=) หรือให้แอดมินตั้งค่าที่หน้า “ตั้งค่าระบบ” แล้วรีเฟรชด้วย Ctrl+Shift+R

ขึ้น “กำลังลองเชื่อมต่อใหม่…” นานผิดปกติ

เน็ต/เซิร์ฟเวอร์สะดุดชั่วคราว ระบบจะเชื่อมกลับให้เองเมื่อเน็ตกลับมา ไม่ต้องปิดเว็บ — ถ้านานเกิน 1–2 นาที ลองกด Ctrl+Shift+R

เห็นข้อมูลไม่ครบ / วันที่ไม่ตรง

ตรวจว่าเลือก วันที่ ถูก (ปุ่มปฏิทินบนซ้าย) — ข้อมูลแสดงตามวันที่เลือก

คนขับส่งเสร็จแล้ว แต่หน้าออฟฟิศยังไม่เปลี่ยน

รอไม่กี่วินาที ระบบซิงค์สถานะให้อัตโนมัติ — หรือกดปุ่ม “รีเฟรช” ที่แดชบอร์ดเพื่อดึงทันที
